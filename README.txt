QUICK START GUIDE
-----------------

1. UPLOAD TO WEB HOSTING
   - Use FTP client (FileZilla recommended)
   - Upload ALL files to your website's root directory (public_html or www)
   - Ensure index.html is in the root folder

2. TEST YOUR WEBSITE
   - Visit your domain in a web browser
   - Test all pages:
     * Homepage
     * Booking page
     * Admin login
   - Verify all images and videos load

3. IMPORTANT: CHANGE ADMIN PASSWORD
   - Current username: admin
   - Current password: terra2025
   - Contact George Dorochov to change credentials
