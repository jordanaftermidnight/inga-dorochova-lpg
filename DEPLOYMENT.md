# 🚀 Free Hosting Options for Inga Dorochova LPG Website

## 🌟 Recommended Free Hosting Platforms

### 1. **Netlify** (Recommended)
- **Website**: [netlify.com](https://netlify.com)
- **Why Choose**: Best for static sites, automatic HTTPS, custom domains
- **Steps**:
  1. Create free account at netlify.com
  2. Drag & drop your project folder OR connect to GitHub
  3. Your site goes live instantly with a netlify.app subdomain
  4. Optional: Add custom domain (IngaDorochova.com)

### 2. **Vercel**
- **Website**: [vercel.com](https://vercel.com)
- **Why Choose**: Excellent performance, free SSL, easy deployment
- **Steps**:
  1. Sign up at vercel.com
  2. Import your project
  3. Deploy with one click

### 3. **GitHub Pages**
- **Website**: [pages.github.com](https://pages.github.com)
- **Why Choose**: Free with GitHub account, version control
- **Steps**:
  1. Create GitHub repository
  2. Upload your files
  3. Enable Pages in repository settings

### 4. **Firebase Hosting**
- **Website**: [firebase.google.com](https://firebase.google.com)
- **Why Choose**: Google infrastructure, fast CDN
- **Steps**:
  1. Create Firebase project
  2. Install Firebase CLI
  3. Deploy with `firebase deploy`
